# private_bond_customer_front

Customer web app for the private bond platform. The admin and broker app lives in a separate repo, `private_bond_admin_front`.

## Features

- **Framework**: [React 19.2](https://react.dev/)
- **Build Tool**: [Vite 8](https://vite.dev/) with `@vitejs/plugin-react` (Oxc, no React Compiler)
- **Routing**: [TanStack Router](https://tanstack.com/router/latest) (file-based)
- **Data Fetching**: [TanStack Query](https://tanstack.com/query/latest)
- **Client State**: [Zustand](https://zustand.docs.pmnd.rs/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (Radix, `vega` style)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **HTTP Client**: [Axios](https://axios-http.com/)
- **Schema Validation**: [Zod](https://zod.dev/)
- **Linting and Formatting**: [Biome](https://biomejs.dev/)

## Getting Started

You need [Node.js](https://nodejs.org/) 22+ and [pnpm](https://pnpm.io/).

1.  **Install dependencies:**

    ```bash
    pnpm install
    ```

2.  **Point the dev proxy at the backend** (optional, defaults to `http://localhost:8080`):

    ```bash
    # .env.development
    API_PROXY_TARGET=http://localhost:8080
    ```

3.  **Run the development server:**

    ```bash
    pnpm dev
    ```

    The application will be available at `http://localhost:5174` (the admin app uses 5173, so both can run at once).

### Root files

- **`public`**: Static files served as-is, not processed by Vite (favicon).
- **`.env.development` / `.env.staging` / `.env.prod`**: Environment per mode. See [Environment Variables](#environment-variables).
- **`biome.json`**: Lint and format rules. Skips `routeTree.gen.ts` and `components/ui`.
- **`components.json`**: shadcn/ui config (style, base color, aliases). Used by `shadcn add`.
- **`index.html`**: Vite entry HTML. Mounts `#root` and loads `src/main.tsx`.
- **`tsconfig.json`**: Root config that references the two configs below. Also holds the `@/*` path for shadcn.
- **`tsconfig.app.json`**: TypeScript config for browser code in `src`.
- **`tsconfig.node.json`**: TypeScript config for `vite.config.ts` (Node).
- **`vite.config.ts`**: Vite config: TanStack Router plugin (generates the route tree and code-splits each route), React, Tailwind, the `@` alias, the dev port and the `/api` proxy.

### `src` entry files

- **`src/main.tsx`**: Entry point. Mounts the providers (TanStack Query, Router, Toaster) and registers the global 401 handler. It is the only file that imports both the router and the fetcher, which keeps them free of an import cycle.
- **`src/router.ts`**: Creates the router with `context: { queryClient }` and registers its types.
- **`src/routeTree.gen.ts`**: Generated by the router plugin. **Do not edit.** It is committed because `tsc -b` needs it.
- **`src/index.css`**: Tailwind import and the shadcn theme tokens (light and dark).
- **`src/vite-env.d.ts`**: Types for `import.meta.env`. Add new `VITE_*` variables here.

### `src/routes`: pages (file-based routing)

The folder path is the URL:

- A folder prefixed with `_` is a pathless layout. It groups routes under a shared layout and guard, but does not appear in the URL (`_customer/contracts/index.tsx` is `/contracts`).
- `route.tsx` is the layout and `beforeLoad` guard of its folder.
- `index.tsx` is the page at that path.
- `$param` folders are dynamic segments (`contracts/$contractId/index.tsx` is `/contracts/:contractId`).

Files:

- **`__root.tsx`**: Top route. Declares the router context type (`queryClient`) and mounts the Router and Query devtools (dev only).
- **`_public/route.tsx`**: Layout for pages that need no session. Redirects to `/` when a session is already cached.
- **`_public/login/index.tsx`**: Login page (placeholder for now).
- **`_customer/route.tsx`**: Protected area. Runs `requireAuth` in `beforeLoad` and renders `CustomerLayout`.
- **`_customer/index.tsx`**: Home page (`/`).

### `src/components`: UI

- **`ui`**: shadcn/ui primitives (button, sonner). Add new ones with `pnpm dlx shadcn@latest add <name>`. Do not rewrite them by hand; excluded from Biome.
- **`layout`**: Page shells. `CustomerLayout` is a mobile-first page with a top header and a centered content column (no sidebar). `PublicLayout` is a centered page for login.
- **`forms`**: Forms (react-hook-form + zod), e.g. `login-form.tsx`.
- **`<domain>`** (add when needed): components for one feature, e.g. `components/contract/` (preview, signature pad).

### `src/hooks`

Reusable React hooks. Empty for now.

### `src/lib`: infrastructure (no UI)

- **`fetcher.ts`**: The axios instance (`baseURL`, `withCredentials`, 20s timeout), the 401 interceptor, `fetchAndValidate(url, schema, options)` that validates responses with zod, and `ApiError` (keeps the HTTP status).
- **`query-client.ts`**: The `QueryClient` singleton and its defaults (2 min `staleTime`, no retry on 4xx).
- **`auth.ts`**: `requireAuth(queryClient)` for a route's `beforeLoad`.
- **`utils.ts`**: `cn` (class name merge) and `showToast`.
- **`types.ts`**: Shared types (`PaginationParams`).

### `src/queries`: API layer, one folder per domain

- **`type.ts`**: zod schemas and the types inferred from them (`ContractSchema`, `ContractType`).
- **`query.ts`**: Fetch functions that call `fetchAndValidate` (`getContracts`, `signContract`, ...).
- **`options.ts`**: The query key factory (`contractKeys`) and `queryOptions` builders used by `useQuery`, `useSuspenseQuery` and route loaders.

`auth/` is the first domain: `MeSchema`, `getMe` and `meOptions`.

### `src/stores`: Zustand

Client-only state, e.g. the steps of the contract signing flow. Empty for now.

**Rule:** server data (including the current user) stays in TanStack Query. Do not copy it into a store.

### `src/assets`

Images and files imported from code. Vite bundles and hashes them. Files that must keep their name go in `public`.

## Adding a New Domain

Example for `contract`:

```
src/queries/contract/type.ts                    ContractSchema, ContractType
src/queries/contract/query.ts                   getContracts, getContractById, signContract
src/queries/contract/options.ts                 contractKeys, contractsOptions(), contractOptions(id)
src/components/contract/                        contract-specific components
src/routes/_customer/contracts/index.tsx        list page (/contracts)
src/routes/_customer/contracts/$contractId/index.tsx   detail page (/contracts/:contractId)
src/stores/sign-flow-store.ts                   signing wizard state, if needed
```

## Auth Flow

The session is an httpOnly cookie set by the backend. The frontend never reads or stores a token.

```
open a /_customer page
  -> routes/_customer/route.tsx beforeLoad
  -> lib/auth.ts requireAuth
  -> queryClient.ensureQueryData(meOptions())      queries/auth/options.ts
  -> getMe() -> fetchAndValidate('auth/me', MeSchema)
  -> GET /api/auth/me (cookie sent, withCredentials)
       200: page renders; components read the user with useSuspenseQuery(meOptions())
       error: redirect to /login

any request returns 401 later
  -> fetcher interceptor -> handler in main.tsx
  -> queryClient.clear(), toast if the user was signed in, navigate to /login
```

## Environment Variables

| Variable | File | Purpose |
|---|---|---|
| `VITE_API_URL` | all `.env.*` | Axios `baseURL`. `/api` keeps requests same-origin so the cookie is sent. |
| `API_PROXY_TARGET` | `.env.development` | Backend address for the dev proxy. Not exposed to the browser (no `VITE_` prefix). |

In staging and production, `/api` must be reverse-proxied to the backend (nginx).
